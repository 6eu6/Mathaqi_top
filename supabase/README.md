# لوحة تحكم مذاقي توب — دليل التشغيل

لوحة تتيح تعديل **المنيو والأسعار والعروض والأطباق وأرقام التواصل ونصوص الأقسام**،
مع **رفع الصور من الجوال**، وكل تعديل يظهر على الموقع **فوراً** بدون إعادة نشر.

---

## كيف يعمل النظام

| الجزء | أين | ملاحظة |
|---|---|---|
| الموقع | `index.html` | يُرسم فوراً بمحتواه المدمج، ثم يجلب آخر محتوى من قاعدة البيانات ويستبدله فقط إن تغيّر |
| اللوحة | `mt-panel-20c00ee28435/` | صفحة مستقلة على نفس الدومين، محمية بتسجيل دخول |
| البيانات | Supabase | جداول مسبوقة بـ `mathaqi_` + صلاحيات RLS |
| الصور | Supabase Storage | دلو `mathaqi-media` |

**إذا تعطّلت قاعدة البيانات أو انقطع الإنترنت، يبقى الموقع يعمل بمحتواه الثابت كما هو** — لا صفحة بيضاء ولا خطأ.

---

## خطوات التشغيل (٤ خطوات، مرة واحدة)

### ١) أنشئ الجداول
Supabase Dashboard ← **SQL Editor** ← **New query** ← الصق كامل ملف
[`setup.sql`](setup.sql) ← **Run**.

الملف آمن على أي مشروع قائم: كل الجداول مسبوقة بـ `mathaqi_`، ولا يعدّل أو يحذف
أي شيء موجود، ولا يغيّر أي إعداد مشترك. وتشغيله أكثر من مرة لا يضرّ.

### ٢) أنشئ حساب المدير
Supabase ← **Authentication ← Users ← Add user** ← ضع البريد وكلمة المرور،
**وفعّل `Auto Confirm User`**.

### ٣) امنح الحساب صلاحية التعديل
في **SQL Editor** شغّل (مع وضع بريدك):

```sql
insert into public.mathaqi_admins (user_id, label)
select id, 'مدير مذاقي توب' from auth.users where email = 'ضع-البريد-هنا'
on conflict (user_id) do nothing;
```

بدون هذه الخطوة **لا أحد يستطيع التعديل** — وهذا هو المقصود.

### ٤) اربط الموقع بالمشروع
Supabase ← **Project Settings ← API** ← انسخ:

- `Project URL`
- `anon` `public` (المفتاح العام)

وضعهما في `assets/js/mt-config.js`:

```js
window.MT_CONFIG = {
  SUPABASE_URL: "https://xxxxxxxx.supabase.co",
  SUPABASE_ANON_KEY: "eyJhbGciOi..."
};
```

ثم ارفع التغيير (commit + push) — وينتهي الإعداد.

## الأمان — اقرأ هذا

- **المفتاح العام آمن للنشر.** هو مصمَّم ليكون في الصفحة. الحماية الحقيقية من
  صلاحيات RLS: القراءة مسموحة للجميع، والكتابة **فقط** لمن هو مسجَّل في جدول
  `mathaqi_admins`. حتى لو سجّل شخص حساباً جديداً، لا يستطيع تعديل حرف واحد.
- **الرابط السرّي ليس حماية.** هو يخفي اللوحة عن الفضوليين ومحركات البحث فقط
  (الصفحة تحمل `noindex`). الذي يحمي فعلاً هو تسجيل الدخول.
- **إذا كان المستودع عاماً على GitHub، فاسم مجلد اللوحة ظاهر فيه.** إن أردت
  إخفاءه فعلاً، اجعل المستودع خاصاً (Vercel يستمر بالنشر طبيعياً).
- استخدم كلمة مرور قوية، وغيّرها من تبويب **الحساب** داخل اللوحة.
