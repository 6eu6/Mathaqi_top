## نظرة عامة

موقع تعريفي احترافي لمطعم وكافيه **مذاقي توب**، مبني بصفحة واحدة (Single Page)
بلغة عربية أساسية وإنجليزية ثانوية، مع دعم كامل للوضعين **الليلي والنهاري**
واتجاه **RTL**. لا يعتمد على أي إطار عمل — HTML و CSS و JavaScript خالص، سريع وخفيف.

### المميزات
- 🎨 هوية بصرية مخصّصة (ذهبي · بُنّي داكن · كريمي) مستوحاة من شعار المطعم.
- 🌙 تبديل **دارك / لايت** يحفظ اختيار الزائر ويحترم إعداد النظام.
- 🕌 تصميم عربي RTL أنيق بخطوط مختارة (Aref Ruqaa · El Messiri · Tajawal).
- 🍢 أيقونات SVG مرسومة يدوياً خصيصاً لكل تصنيف (لا مكتبات جاهزة).
- 🖼️ صور منتجات حقيقية مفرّغة الخلفية بجودة عالية (WEBP) في قسم الأطباق والعروض.
- 🏷️ قسم **العروض** كامل (عروض الخميس والجمعة، كومبو العائلة، خصم الطلاب) بأسعار قبل/بعد.
- 📋 المنيو كامل مع فلترة حسب التصنيف والأسعار بالريال اليمني.
- 📱 متجاوب بالكامل مع الجوال واللوحي والحاسب.
- ⚡ خفيف وسريع، جاهز للنشر على GitHub Pages.

## التشغيل محلياً

```bash
# أي خادم ثابت بسيط
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

## النشر (GitHub Pages)

يُنشر الموقع تلقائياً عند كل تحديث للفرع `main` عبر
[GitHub Actions](.github/workflows/pages.yml).
فعّل الميزة من: **Settings → Pages → Build and deployment → GitHub Actions**.

---

## إضافة صور الأطباق

ضع صور المنتجات الحقيقية في `assets/img/food/` بالأسماء التالية لتظهر تلقائياً في المعرض:

`shawarma.jpg` · `pizza.jpg` · `burger.jpg` · `broast.jpg` · `zinger.jpg` · `fajita.jpg`

حتى تُضاف الصور، يعرض الموقع بديلاً أنيقاً (أيقونة) بدل أي عنصر مكسور.
