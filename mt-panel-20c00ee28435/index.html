  1. Supabase ← SQL Editor ← الصق ملف supabase/setup.sql ← Run
  2. Supabase ← Authentication ← Users ← Add user (فعّل Auto Confirm)
  3. شغّل سطر ربط المدير الموجود في نهاية ملف الإعداد
  4. Supabase ← Project Settings ← API ← انسخ URL و anon public إلى mt-config.js
